# 전공길잡이 🎓

대학생들이 복수전공, 부전공, 융합전공, 전과 등을 고민할 때 자신의 학점, 이수 현황, 관심 분야 등을 바탕으로 신청 가능 여부를 확인할 수 있는 웹서비스입니다.

## 🌟 주요 기능

### 1. 학생 정보 입력
- 학번, 소속 학과, 현재 학년 입력
- 평균 평점(GPA)과 취득 학점 입력
- 간편한 입력 폼으로 빠른 정보 등록

### 2. 신청 가능 여부 확인
- 복수전공, 부전공, 융합전공, 전과의 신청 가능 여부 즉시 확인
- 각 제도별 조건 충족 상황 명확하게 표시
- 부족한 조건과 개선 방향 제시

### 3. 조건 비교
- 여러 전공 제도의 요구사항을 한눈에 비교
- 최소 평점, 최소 학점, 최소 학년 조건 비교표

## 📊 신청 조건

| 전공 제도 | 최소 평점 | 최소 학점 | 최소 학년 |
|---------|---------|---------|--------|
| 복수전공 | 3.0 | 36학점 | 2학년 |
| 부전공 | 2.5 | 30학점 | 1학년 |
| 융합전공 | 2.8 | 33학점 | 2학년 |
| 전과 | 3.5 | 40학점 | 3학년 |

## 🚀 시작하기

### 설치 방법

1. 저장소 클론
```bash
git clone https://github.com/luminous516-maker/major_road-map.git
cd major_road-map
```

2. 웹 브라우저에서 `index.html` 파일 열기
   - 또는 라이브 서버 사용: VSCode의 Live Server 확장 프로그램 이용

### 사용 방법

1. "신청 가능 여부 확인하기" 버튼 클릭
2. 학생 정보 입력 (학번, 학과, 학년, 평점, 이수학점)
3. "신청 가능 여부 확인" 버튼 클릭
4. 결과 확인 및 전공 비교
